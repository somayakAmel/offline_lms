# offline_lms

Mini offline LMS with a video lesson player.
Arabic-first with RTL support; English is available as a second language.

## Run

```sh
flutter pub get
flutter run
```

## Structure

```text
lib/
├── main.dart
└── src/
    ├── app/        app widget and startup
    └── core/       DI, router, theme, localization
```
